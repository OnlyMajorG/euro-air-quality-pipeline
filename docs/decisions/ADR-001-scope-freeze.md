# ADR-001: Eingefrorener Projektumfang

## Status

Akzeptiert

## Kontext

Das Projekt soll die geforderten Data-Engineering-Schritte erfüllen, ohne unkontrolliert erweitert zu werden.

## Entscheidung

Der Umfang umfasst europäische Luftqualitätsmuster, die EEA Downloads API mit PostgreSQL-Bronze-Speicher, Wikipedia-Web-Scraping, die Open-Meteo-REST-API, Kafka, Spark Structured Streaming, Parquet, Jupyter Notebooks, Matplotlib und Mermaid-Diagramme.

Nicht vorgesehen sind Dashboards, ML-Modelle, Airflow, dbt, Cloud-Bereitstellung und Produktionsbetrieb.
