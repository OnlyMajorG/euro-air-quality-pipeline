# Implementation Documentation

This folder records what was implemented, why it was implemented, and what was
intentionally left out.

The documentation must stay phase-aware:

- Phase 0 documents scaffolding only.
- Phase 1 may document source feasibility work only after Phase 0 cleanup.
- Later phases may document actual ingestion, streaming, transformations, and
  analysis when those phases are explicitly active.

Each implementation document should include:

- Objective.
- Files changed or added.
- Scope boundary.
- Mermaid diagram when useful.
- Validation performed.
- Known limitations.
